# ربات تلگرامی دانلودر + آپسکیلر عکس

## قابلیت‌ها

1. **دانلود از لینک** - تشخیص خودکار پلتفرم و دانلود محتوا:
   - یوتیوب → ویدیو
   - ساندکلود → صدا (mp3)
   - اینستاگرام (فقط پست/ریلز عمومی) → ویدیو
   - اسپاتیفای → صدا (mp3)، با متادیتای واقعی اسپاتیفای

2. **آپسکیل عکس** - وقتی عکس بفرستی، دکمه‌ی x2 یا x4 نشون داده می‌شه و
   Real-ESRGAN ابعاد و جزئیات تصویر رو بهبود می‌ده، بدون تغییر رنگ/نور.

## ⚠️ نکته‌ی مهم درباره‌ی اسپاتیفای (حتماً بخون)

هیچ راه قانونی برای دانلود مستقیم فایل کامل صوتی از اسپاتیفای (یا دیزر،
اپل‌میوزیک و مشابه) وجود نداره، چون استریم‌هاشون با DRM محافظت می‌شه.
روشی که این پروژه استفاده می‌کنه:

1. از لینک اسپاتیفای، **متادیتای واقعی** (اسم آهنگ، خواننده، آلبوم، کاور)
   از API رسمی اسپاتیفای گرفته می‌شه.
2. با همون اسم/خواننده و با تطبیق مدت‌زمان، نزدیک‌ترین ویدیوی متناظر در
   یوتیوب پیدا می‌شه.
3. صدای همون ویدیوی یوتیوب دانلود و به mp3 192kbps تبدیل می‌شه.
4. فایل نهایی با متادیتای واقعی اسپاتیفای (نه یوتیوب) تگ‌گذاری می‌شه.

یعنی فایل صوتی نهایی از یوتیوب میاد، نه مستقیماً از اسپاتیفای. کیفیت
معمولاً بین ۱۲۸ تا ۱۹۲kbps واقعی هست (محدودیت خود منبع یوتیوب، نه چیزی که
ما بتونیم دورش بزنیم).

## اضافه کردن به گروه و چنل

بات الان توی چت خصوصی، گروه، و چنل کار می‌کنه: هر جا لینک یا عکس بفرستن،
تشخیص می‌ده و محتوا رو **به‌صورت ریپلای روی همون پیام** آپلود می‌کنه، و
پیام "در حال دریافت..." رو بعد از تمام‌شدن پاک می‌کنه.

**برای گروه:**
1. قبل از اضافه‌کردن بات به گروه، برو پیش [@BotFather](https://t.me/BotFather)
   → `/setprivacy` → بات‌ت رو انتخاب کن → `Disable`.
   این کار لازمه چون به‌صورت پیش‌فرض بات‌ها توی گروه فقط پیام‌هایی که با
   `/` شروع می‌شن یا منشن/ریپلای به خودشون هستن رو می‌بینن؛ با غیرفعال
   کردن Privacy Mode، بات همه‌ی پیام‌های گروه (از جمله لینک‌ها) رو می‌بینه.
   اگه بات از قبل توی گروهه، بعد از تغییر این تنظیم باید یه بار حذفش کنی
   و دوباره اضافه‌ش کنی تا اعمال بشه.
2. بات رو به گروه اضافه کن، نیازی به ادمین‌کردنش نیست (مگه بخوای پیام‌های
   بقیه رو هم پاک کنه که فعلاً همچین قابلیتی نداره).

**برای چنل:**
1. بات رو به چنل اضافه کن و **ادمینش کن**، با حداقل این دسترسی‌ها:
   - Post Messages (برای فرستادن محتوا)
   - Edit Messages (برای آپدیت‌کردن پیام "در حال پردازش...")
   - Delete Messages (برای پاک‌کردن پیام "در حال پردازش..." بعد از اتمام)
2. هر پستی که توی چنل با لینک یا عکس گذاشته بشه (چه توسط خودت چه بقیه‌ی
   ادمین‌ها) به‌صورت خودکار پردازش می‌شه.
3. نکته: پست‌های چنل با پیام‌های عادی فرق دارن (تلگرام اونا رو جدا
   می‌فرسته)، این پروژه هر دو نوع رو پشتیبانی می‌کنه.

## پیش‌نیازها

- Python 3.10+
- ffmpeg (به‌صورت خودکار از طریق پکیج `imageio-ffmpeg` فراهم می‌شه، نیازی
  به نصب جداگانه روی سرور نیست)
- یک بات‌توکن از [@BotFather](https://t.me/BotFather)
- (اختیاری، برای قابلیت اسپاتیفای) Client ID/Secret از
  [Spotify Developer Dashboard](https://developer.spotify.com/dashboard)

## نصب

```bash
git clone <این-ریپازیتوری>
cd telegram_bot
python -m venv venv
source venv/bin/activate  # ویندوز: venv\Scripts\activate

# اول تورچ نسخه‌ی CPU رو نصب کن (مهم! نگاه کن به requirements.txt)
pip install torch==2.0.1+cpu torchvision==0.15.2+cpu \
    --index-url https://download.pytorch.org/whl/cpu

# بقیه‌ی وابستگی‌ها
pip install -r requirements.txt

# دانلود مدل‌های آپسکیل (یک‌بار، حدود ۱۰۰ مگابایت مجموعاً)
python scripts/download_models.py

# فایل env بساز و توکن‌ها رو پر کن
cp .env.example .env
# .env رو ویرایش کن و TELEGRAM_BOT_TOKEN و (اختیاری) SPOTIFY_* رو پر کن

python run.py
```

## دیپلوی روی Render

1. یه **Web Service** یا **Background Worker** جدید بساز و ریپو رو وصل کن.
2. **Build Command:**
   ```
   pip install torch==2.0.1+cpu torchvision==0.15.2+cpu --index-url https://download.pytorch.org/whl/cpu && pip install -r requirements.txt && python scripts/download_models.py
   ```
3. **Start Command:**
   ```
   python run.py
   ```
4. متغیرهای محیطی (`TELEGRAM_BOT_TOKEN`, `SPOTIFY_CLIENT_ID`,
   `SPOTIFY_CLIENT_SECRET`, `MAX_CONCURRENT_UPSCALES`) رو توی بخش
   Environment در پنل Render تنظیم کن.
5. **نکته‌ی مهم درباره‌ی دیسک**: دیسک پیش‌فرض Render موقتیه (ephemeral) و
   با هر دیپلوی جدید پاک می‌شه. مدل‌ها هر بار توی build دوباره دانلود
   می‌شن (چون توی Build Command هستن) که مشکلی نیست، فقط کند‌تر می‌شه.
   اگه می‌خوای این تکرار نشه، می‌تونی یه Persistent Disk به سرویس اضافه
   کنی و `WEIGHTS_DIR` رو به مسیر اون دیسک اشاره بدی.
6. چون این پروژه با `run_polling` کار می‌کنه (نه webhook)، نیازی به دامنه
   یا HTTPS نیست - فقط باید سرویس همیشه روشن بمونه (نه پلن رایگانی که
   خواب می‌ره).

## چک‌لیست تست (حتماً قبل از استفاده‌ی واقعی انجام بده)

- [ ] `/start` جواب می‌ده
- [ ] لینک یوتیوب → ویدیو دانلود و ارسال می‌شه
- [ ] لینک ساندکلود → mp3 دانلود و ارسال می‌شه
- [ ] لینک پست/ریلز عمومی اینستاگرام → ویدیو دانلود و ارسال می‌شه
- [ ] لینک اسپاتیفای → mp3 با کاور و تگ درست ارسال می‌شه
- [ ] لینک نامعتبر/ناشناخته → پیام خطای مناسب (نه کرش)
- [ ] لینک خصوصی/حذف‌شده → پیام خطای مناسب (نه کرش)
- [ ] فایل خیلی بزرگ (>۵۰ مگابایت) → پیام خطای مناسب به‌جای کرش
- [ ] ارسال عکس → دکمه‌های x2/x4 نمایش داده می‌شن
- [ ] زدن x2 → عکس بزرگ‌تر و واضح‌تر با همون رنگ‌ها برمی‌گرده (این رو با
      چشم چک کن که رنگ قرمز/آبی جابه‌جا نشده باشه)
- [ ] زدن x4 → مثل بالا
- [ ] فرستادن دو عکس پشت‌سر‌هم و زدن دکمه‌ها → صف پردازش درست کار می‌کنه
      و سرور کرش نمی‌کنه
- [ ] بعد از `/setprivacy` → `Disable` و اضافه‌کردن بات به یه گروه تستی،
      یه لینک یوتیوب توی گروه بفرست → بات باید ریپلای کنه و محتوا رو
      بفرسته (نه فقط توی چت خصوصی)
- [ ] بات رو ادمین یه چنل تستی کن، یه لینک توی چنل پست کن → بات باید
      محتوا رو به‌صورت ریپلای روی همون پست بفرسته و پیام "در حال
      دریافت..." رو پاک کنه

## محدودیت‌های شناخته‌شده

- فایل‌های بزرگ‌تر از ۵۰ مگابایت (محدودیت خود تلگرام برای بات‌ها) ارسال
  نمی‌شن.
- عکس‌های خیلی بزرگ (بیشتر از ۲۰۰۰ پیکسل در ضلع بلندتر) رد می‌شن تا سرور
  CPU-only کرش نکنه؛ این عدد رو می‌شه توی `bot/services/image_upscaler.py`
  (متغیر `MAX_INPUT_DIMENSION`) تغییر داد.
- عکس‌های PNG با پس‌زمینه‌ی شفاف: کانال آلفا حذف می‌شه (تبدیل به RGB ساده)،
  چون Real-ESRGAN با شفافیت کار نمی‌کنه.
- محتوای خصوصی اینستاگرام (نیازمند لاگین) پشتیبانی نمی‌شه، طبق تصمیمی که
  گرفتیم فقط پست/ریلز عمومی پشتیبانی می‌شه.
- روی سرور CPU-only، هر آپسکیل ممکنه از چند ثانیه تا چند دقیقه طول بکشه،
  بسته به سایز عکس و قدرت سرور - این محدودیت سخت‌افزاریه، نه باگ.
